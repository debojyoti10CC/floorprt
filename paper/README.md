# IEEE whitepaper source

`main.tex` and `references.bib` are the Overleaf-ready IEEE conference source. To compile it in Overleaf:

1. Create a blank project and upload both files from this folder.
2. Set `main.tex` as the main document.
3. Select pdfLaTeX and compile; the citations resolve from `references.bib`.

The figures are generated in LaTeX with PGFPlots, so there are no external chart images to upload. The paper reports one measured trader-history venue (Polymarket). The multi-market section is a documented source-access study; it does not claim new Opinion, Predict.fun, Kalshi, Limitless, Gemini, or Manifold observations.
