## Start the local stack

Use Node 24 and pnpm 10.20.0.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

| Service | Local address |
| --- | --- |
| AQRA app | `http://127.0.0.1:3000/` |
| Read API | `http://127.0.0.1:8787/api/v1/health` |
| Anvil RPC | `http://127.0.0.1:8545`, chain 31337 |

The runner compiles and deploys contracts, seeds the local chain and starts the API and app. Keep Anvil on loopback. Local accounts and test USDC are development-only.

## Walk through the credit desk

1. Open the **Data** tab to inspect the historical replay and cohort results.
2. Open **Borrow**, connect the local borrower, enter a `.eth` name or one to four wallets, then load the public history.
3. Review the dated evidence, bond and fixed repayment. Submit the wallet-signed request.
4. Use the local curator account to submit a clearly labeled local report for the request.
5. Switch to a separate local lender, acknowledge the maximum loss and fund the exact request.
6. Repay before maturity, or advance the local clock and settle the default to inspect the bond recovery and shortfall.

For a seeded request using a historically qualifying wallet, run `pnpm underwriting:demo --pending` in a second terminal. The command records test-chain transaction details under `work/underwriting`.

## Reproduce the wider replay

```bash
pnpm underwriting:benchmark
```

This collects the predeclared 12-month sample, audits source boundary blocks and writes a reproducible replay. See [Trader credit](/specifications/REFERENCE_RESEARCH) and the [whitepaper](/whitepaper) for the exact assumptions and limitations.
