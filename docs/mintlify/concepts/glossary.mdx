| Term | Meaning |
| --- | --- |
| Observation | One immutable scalar price/time/source/policy commitment with a single terminal state |
| GEQ | YES wins when the canonical price is greater than or equal to the strike |
| YES / NO | Complementary outcome claims; Solidity enum values 0 / 1 |
| Complete set | Equal whole YES and NO units from one market, backed by one USDC per pair |
| Certified floor | Conditional minimum terminal payout of an accepted pair, not its market value |
| Principal | Amount transferred directly from lender to borrower at funding |
| Total due | Principal plus the entire agreed fixed lender fee |
| Reserve | Unadvanced floor headroom, not a separate insurance fund or cash deposit |
| Beneficiary | Immutable position recipient of settlement residual; claims return to owner on release |
| Lien | One loan's encumbrance of one exact vault position |
| Longstop | Earliest timestamp when anyone may cancel the shared unresolved observation |
| Recorded evidence | Historical reads and receipts, never spend authorization |

## Exact units

- USDC: six decimals. `1 USDC = 1000000` base units.
- Winning claim: `1000000` base units per whole token; losing claim: `0`.
- Canceled claim: `500000` base units per whole token.
- Claim quantities: positive `uint64` whole units, maximum `18446744073709551615` per call.
- Prices/strikes: unsigned integers with observation-specific `priceDecimals` (at most 18); contract price bound `10^36`. Seeded ETH/USD observations use 8 decimals.
- IDs and monetary JSON values: decimal strings. Numeric enum states, chain ID, buffer basis points and log index remain JSON numbers.
- Basis points: 10,000 = 100%; deployed sample reserve is 2,000 = 20%.

Use TypeScript `bigint` for economic arithmetic. Floating-point conversion in charts is only for display geometry, never transaction values.

## State enum values

| Domain | Values |
| --- | --- |
| Observation | `0 UNRESOLVED`, `1 FINALIZED`, `2 CANCELLED` |
| Position | `0 NONE`, `1 OPEN`, `2 ENCUMBERED`, `3 RELEASED`, `4 REDEEMED` |
| Loan | `0 NONE`, `1 FUNDED`, `2 SETTLED`, `3 REPAID` |

IDs start at 1; zero is the absence sentinel. Released positions are not reopened or reused.
