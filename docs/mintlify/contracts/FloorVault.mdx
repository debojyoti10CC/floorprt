Nontransferable exact-inventory positions with immutable owner and beneficiary. Lock recomputes the proof; expected batch context rejects unsolicited deposits. Only the once-bound reciprocal CreditDesk may lien, redeem or release repaid claims. New-lock pauses do not pause exits.
