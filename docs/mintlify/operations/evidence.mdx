## Reproduce, do not relabel

Run [the test commands](/operations/testing) with a fresh compatible local deployment. `pnpm demo` adds transactions and deliberately advances the clock. Repeating it is not a chain reset. Record exact command output and checkout identity when creating a new release record.

A local receipt proves a local EVM execution, not economic value or a public explorer transaction. A fork proves a selected external-code integration on a local test execution, not a public deployment. A screenshot alone proves neither cash transfers nor oracle provenance.
