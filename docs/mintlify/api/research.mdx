`GET /api/v1/research/markets`

Fetches up to 12 active Gamma markets and batches their outcome IDs into the Polymarket CLOB books endpoint. Markets use token IDs for v1 and position IDs for v2. Ask levels are sorted from the best buy price upward. Successful results cache per process for 10 seconds; each upstream request retries once with an 8-second timeout. On upstream failure, a cached result no older than 5 minutes returns with stale=true. Gamma failures without a usable cache return 502. A failed CLOB request leaves discovery metadata available with empty books. External rows are never collateral eligible.

## Request

```bash
curl 'http://127.0.0.1:8787/api/v1/research/markets'
```

## Response contract

The following is a **schema**, not a transaction result. Shared types resolve in the [OpenAPI specification](/api/openapi.json).

```json
{
  "$ref": "#/components/schemas/Research"
}
```

## Status codes

- **200**: Successful read; proof validity is a separate field.
- **500**: Runtime/manifest/RPC error; malformed preview JSON also reaches generic error handling.
- **502**: Gamma/source validation failure; collateralEligible remains false.
