The original blueprint remains in docs/. This log resolves implementation ambiguities before code.

1. **ADR-001 Fixed claims.** Independently authored, immutable, fully USDC-backed ERC-1155 complete sets. Cumulant's parimutuel source and Senthos's sandbox ledger are reference material only.
2. **ADR-002 One observation.** Canonical GEQ predicates share the exact registry observation ID. No per-market resolver or cancellation override exists. Prices are unsigned canonical integers, precision &lt;=18, maximum 1e36.
3. **ADR-003 Whole units.** All claim amounts are uint64 whole tokens. Odd *whole* amounts are valid and cancel at exactly 500,000 micro-USDC per token. SECURITY_AND_QA's “odd amounts blocked” conflicts with this rule if read literally; only fractional units are rejected. Boundary and cancellation tests cover 1 and 3 tokens.
4. **ADR-004 Borrower consent.** A request fixes the exact principal and maximum total due. Partial funding is disallowed. Distinct lender and borrower, one lender per immutable position, fixed debt, 20% buffer rounded upward. Fees are included in the debt cap.
5. **ADR-005 Local first.** Anvil 31337 and mock six-decimal test USDC. Public testnet deployment is separately configured and never implied by a private web preview. External research cannot enter the vault.
6. **ADR-006 Chain authority.** Wallet-signed writes, generated ABIs, receipt confirmation and direct chain reads. Read-only API and reorg-aware event cache cannot spend or certify collateral. No backend signing endpoint.
7. **ADR-007 Scope.** All P0 routes and lifecycle first. P1 generalized solver is a research preview until an onchain bounded verifier exists. Tranche issuance cannot share loan-encumbered inventory; do not fabricate P2 products.
8. **ADR-008 Longstop.** Anyone can cancel the *shared observation* at cancelAfter. Nobody, including resolver, can cancel sooner. Finalize requires resolver and observation time, and every terminal state is immutable. Tests advance Anvil time explicitly.
9. **ADR-009 Economic cutoff.** Mint, lock, request and fund require an unresolved observation strictly before its observationTime. Resolution-time information cannot be used for a new loan while waiting for a resolver. Release and redemption remain available afterward.
10. **ADR-010 No silent shortfall.** Settlement reverts if redeemed funds fall below the certified floor or due. No successful underpayment status. Atomic state transitions precede external monetary calls.
11. **ADR-011 Factory identity.** Factory creates exactly one approved token issuer in its constructor; immutable collateral/registry bindings enforce identical payouts and policies by construction. Vault binds one matching credit desk once; no upgrade or collateral rescue powers.
12. **ADR-012 Delivery stack.** pnpm workspace, Next.js static terminal, Solidity/Foundry, viem, Hono read API. Direct RPC reads make local custody usable during an API outage. Persistent database is optional for P0, as permitted by ARCHITECTURE section 9.

Validation must cover interval endpoints, cancellation, inconsistent observations, backing, callback context, consent, allowance failure atomicity, timing, debt cap and duplicate settlement. A public testnet or CRE claim requires its own recorded execution evidence.

13. **ADR-013 User-directed design.** The user requested Coinbase's DESIGN.md and then supplied a dark institutional command-center reference and an interactive prediction-market constellation concept. The terminal combines that dark product layout with Coinbase Blue, pill actions, Inter 400 display type and JetBrains Mono. The scenario surface is generated from exact payoff math; no fabricated correlations or probability distribution are displayed.
14. **ADR-014 Portable test dependency.** forge-std is vendored under `vendor/` at a pinned commit with original license files. The initial research/install clone is ignored; Git metadata is not removed or distributed.
15. **ADR-015 Final Kimia direction.** The user's latest screenshots and tokens supersede ADR-013's initial palette and primary typography: Poppins, black/charcoal surfaces, pale periwinkle, rounded controls and the supplied concave/convex shadows. Floor retains its own identity. Semantic tokens own component colors; accessible control-boundary and on-accent roles extend the supplied foundations. The extracted documentation-surface label is treated as uncertain because the actual references depict trading interfaces. The implementation-ready rules are in DESIGN_SYSTEM.md.
16. **ADR-016 Working core extension.** The user's request for a non-mock mechanism authorizes external Sepolia collateral/feed support and atomic full fixed-due repayment. The local faucet remains isolated to loopback Anvil. Public deployment never creates a mock token. Canonical external interfaces are verified on a pinned Sepolia fork, clearly separated from public receipts. This extends ADR-005 and the repayment portion of ADR-007 without claiming RFQs or tranches.
17. **ADR-017 Historical feed rule.** A source-bound permissionless adapter accepts only a complete publication at/before observation time and its immediate successor after it, within a fixed window. Unsupported feed gaps or phase transitions fail closed and retain shared longstop cancellation. No arbitrary-price resolver is available in the public deployment path.
18. **ADR-018 Operational recovery.** Initial composer selection uses live eligible markets. User edits take priority over delayed metadata or RPC initialization. Closed selections show an explicit recovery action; contracts retain their maturity guards. Repetitive explanation cards move to documentation. Generated pixel avatars identify wallet addresses; capital-flow geometry uses confirmed event amounts.

19. **ADR-019 Trader credit pivot (6 November 2026).** The wallet-history pilot uses a separate TraderCreditDesk and a first-loss stablecoin bond. It leaves the legacy floor vault and its certified-debt invariant intact. Historical monthly P&amp;L is evidence for a decision, with separate simulated recoveries and an explicit bond-only loss. A loan requires an authenticated report for the exact evidence, one borrower, one consenting lender, and exact token movements. The attestation never gains custody of the venue account. Wallet links are request-bound and cannot be concurrently pledged to a second request. ENS records are discovery and display. Arkiv supplies expiring evidence packets to the lender board. For the initial demo, lending is restricted to local test funds and the report sender is explicitly labelled as a local forwarder. Public CRE delivery requires a separately configured forwarder and deployed workflow identity.
